PRU_RPMsg_LED0
--------------

PRU_RPMsg_LED0 can be controlled by writing directly to the /dev/rpmsgX
entry from the command line, or by running the example script pru0_led.sh.

The /dev/rpmsgX entry that is created when a PRU core is booted is the entry
associated with that specific PRU core. For an example of writing to /dev/rpmsgX
from the command line, reference the RPMsg Quick Start Guide.
